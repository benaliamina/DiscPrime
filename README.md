# DiscPrime

DiscPrime is a software framework for real-time data ingestion, processing, and distribution across heterogeneous processor platforms.

DiscPrime is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/DiscPrime.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
